# Account and security

## Changing your password

Settings → Account. You must enter your current password to set a new one. If
you signed in with Google, there is no password on the account to change, and
the form is not shown.

## Two-factor authentication

Two-factor authentication asks for a six-digit code from an authenticator app,
in addition to your password, whenever you sign in.

To turn it on, open Settings → Account and start two-factor setup. Scan the QR
code with an authenticator app such as Google Authenticator or Authy, then enter
the code it shows to confirm. Two-factor is only switched on once you have
confirmed that code.

You are then given ten **backup codes**. Each works once, and they are your way
back in if you lose the authenticator app. They are shown only at that moment,
so save them somewhere safe. You can generate a fresh set later, which
invalidates the old ones.

To turn two-factor off you need both your password and a current code (or a
backup code).

## Profile picture

Settings → Account lets you upload a new profile picture.
